# Project Notes

This project is kept in the original STM32CubeIDE-style structure used for the assignment. The code is intentionally preserved close to the final submitted version.

## Main Source Files

- `Src/main.c`: main game logic, peripheral initialization, UART CLI, sensor handling, OLED output, and game state handling.
- `Inc/main.h`: board pin definitions generated by STM32CubeMX.
- `Src/buzzer.c` and `Inc/buzzer.h`: non-blocking buzzer helper.
- `Src/seeedoled.c` and `Inc/seeedoled.h`: OLED display support.
- `Src/Grove_Switch_STM32.c` and `Inc/Grove_Switch_STM32.h`: Grove 5-way switch support.
- `Src/TimerOne_STM32.c` and `Inc/TimerOne_STM32.h`: timer wrapper used by the project.

## Driver Folders

- `B-L4S5I-IOT01/`: board support package for the Discovery kit.
- `Components/`: component drivers for sensors and external ICs.
- `Device/`: CMSIS STM32L4 device headers.
- `Startup/`: startup assembly for the STM32L4S5VI target.

## Clean Repository Choices

- Build outputs are ignored with `.gitignore`.
- The final assignment code is not aggressively refactored, so it remains easy to compare with the submitted/demo version.
- Presentation-style explanation has been moved out of the README so the repository homepage stays concise.
